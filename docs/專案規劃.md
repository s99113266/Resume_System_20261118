## 2. 專案方向與範圍

**目的**：提供一份可線上瀏覽與編輯的個人履歷，資料集中存放、整份存取。

**階段規劃**

| 階段 | 內容 | 狀態 |
| ---- | ---- | ---- |
| 階段 0 | 履歷資料合輯、格式定義、驗證腳本、專案文件 | 已完成 |
| 階段 1 | 履歷檢視頁（唯讀呈現、中英文簡介切換、列印） | 已完成 |
| 階段 2 | 履歷編輯頁（表單編輯、清單增刪排序、整份儲存並附動作欄位） | 未開始 |
| 作品集 | 資料結構已定義，畫面暫不排入階段 1、2 | 暫時保留 |

**不在範圍內**：多份履歷管理、帳號與權限、後端管理介面、任何第三方 UI 套件。

## 3. 系統架構

分成三層，職責不得互相滲透：

| 層級 | 內容 | 職責 |
| ---- | ---- | ---- |
| 文件層 | README、專案規劃、檔案關聯、API、log | 記錄規則、載入關係、資料動作對照與歷史 |
| 資料層 | data/resume.json、data/resume.schema.json、scripts/validate-resume.mjs | 唯一資料來源、格式定義、格式檢查 |
| 前端層 | HTML 頁面、共用 CSS/JS、單頁 CSS/JS | 呈現與編輯；所有資料存取經共用 JS 呼叫 API |

**資料流**：頁面載入 → 共用 JS 呼叫讀取 API 一次取得整份合輯 → 單頁 JS 依區段拆成頁面各區塊 → 使用者操作（僅修改記憶體） → 單頁 JS 將各區塊組回整份合輯並設定隱藏動作欄位 → 共用 JS 一次送出整份合輯 → 依回應的成功旗標顯示結果。

## 4. 資料規範（摘要）

以下為全專案共通的資料規則，欄位細節與「值 → 動作」對照請看 docs/API.md。

| 規則 | 內容 |
| ---- | ---- |
| 單一合輯 | 全部區段合併成一份 JSON，區段為根層鍵：basicInfo、education、experience、portfolio、skills、certificates、desiredPositions、introduction、introductionEn |
| 整份存整份取 | 讀取與儲存都以整份合輯為單位；禁止只送或只取單一區段 |
| 傳輸封包 | 一次送出整份合輯，封包內含一個隱藏動作欄位（新增、修改、刪除、其他），與 9 個區段同層，不額外巢狀 |
| 儲存內容 | 動作欄位不屬於履歷資料，存檔前取出並丟棄；讀回的合輯不含動作欄位 |
| 編輯頁載入 | 一次讀回整份合輯後，依區段拆成頁面各區塊；拆分只在記憶體，不改變資料結構 |
| 清單增刪 | 只修改記憶體，按下儲存時以整份合輯送出，動作值仍為「修改」 |
| 層數上限 | 最多 3 層（根層 → 區段 → 清單項目欄位）；清單項目內只能放字串或 null |
| 清單項目 | 不使用 id；以陣列索引定位 |
| 肄/畢業 | 只接受中文值「畢業」「肄業」 |
| 離職年月 | 空值（null）代表在職中 |
| 日期格式 | 生日為年-月-日；學歷肄/畢業年分為年-月（可只填年）；經歷起訖為年-月 |
| 空值慣例 | 文字欄位沒內容填空字串；清單沒資料填空陣列 |
| 回應格式 | 只有成功旗標（success），成功為 true、失敗為 false，不細分狀態碼 |

## 6. 共用基礎檔案（必列清單）

> 規則：所有頁面可用的樣式與程式碼都必須放在以下檔案。新增共用檔前，必須先更新本節與 docs/檔案關聯.md。

| 檔案 | 作用 | 使用規則 |
| ---- | ---- | -------- |
| css/base.css | 設計變數（色彩、字級、間距）、樣式重置、字體、版面容器、共用元件（標籤、按鈕、提示訊息、空狀態）、跳至主要內容連結、列印樣式 | 所有頁面第一個載入；只放跨頁共用樣式；顏色與間距一律使用本檔變數；禁止在 HTML 用行內樣式排版 |

| js/ui.js | DOM 建立與查詢、訊息提示、載入狀態、空狀態、共用小工具 | 不得包含欄位名稱與資料格式知識；不得直接呼叫 API |

### 7.2 檢視頁內容與順序

| 順序 | 區段 | 內容 |
| ---- | ---- | ---- |
| 1 | 頁首 | 照片、姓名、希望職缺標籤、手機、信箱 |
| 2 | 簡介 | 中文與英文切換，同時只顯示一種 |
| 3 | 學歷 | 學校、科系、肄/畢業年分、肄/畢業 |
| 4 | 經歷 | 公司、職稱、起訖年月（在職中顯示「至今」）、薪資、工作內容 |
| 5 | 技能 | 標籤列表 |
| 6 | 證照／證書 | 名稱與證照照片 |
| 7 | 作品集 | 目前資料為空，顯示「作品集暫無資料」；有資料時顯示圖片、簡介與連結 |
| 8 | 頁尾 | 列印按鈕、資料來源說明（預覽模式時顯示） |

畫面狀態：載入中、讀取失敗（提供重新載入）、單一區段無資料（顯示該區段空狀態，不隱藏整頁）。

### 7.3 編輯頁內容與操作

| 區塊 | 操作 |
| ---- | ---- |
| 基本資料 | 7 個欄位表單 |
| 學歷清單 | 新增、刪除、上下移 |
| 經歷清單 | 新增、刪除、上下移、在職中切換（勾選後離職年月停用，儲存為 null） |
| 技能、希望職缺 | 輸入後加入、逐項移除、自動去除重複 |
| 證照清單 | 名稱、證照照片網址 |
| 中英文簡介 | 多行文字 |
| 動作欄位 | 隱藏欄位，預設「修改」；建立新履歷時為「新增」；刪除整份履歷時為「刪除」 |
| 儲存列 | 未儲存提示、儲存按鈕、成功與失敗訊息 |

操作原則：編輯只改記憶體中的合輯，按下儲存才整份送出（含隱藏動作欄位）；有未儲存變更時離開頁面需提示。讀取失敗時畫面提供「重新載入」與「建立新履歷」，只有選擇後者才送出「新增」。

## 8. 版面與視覺方向（草案）

| 項目 | 方向 |
| ---- | ---- |
| 版面 | 檢視頁單欄、內容固定最大寬度；編輯頁桌機雙欄（左側區段錨點導覽、右側表單），行動版單欄 |
| 視覺調性 | 專業、克制、以文字為主；強調色只用於主要動作與焦點 |
| 字體 | 系統中文字體優先，不載入外部字型 |
| 間距與元件 | 由 base.css 變數統一；卡片使用細邊框與適度留白，不堆疊陰影 |
| 列印 | 檢視頁可列印：隱藏導覽與按鈕，避免區段被切斷 |
| 響應式 | 小於 768px 單欄；大於等於 1024px 編輯頁雙欄 |
| 無障礙 | 語意標籤、表單 label 綁定、錯誤訊息即時播報、鍵盤可完成所有操作、對比度足夠、圖片提供替代文字 |
| 不使用 | 裝飾性插圖、華麗動畫、外部圖示庫 |
| 深色模式 | 待確認，未定案前不實作 |

## 10. 檔案與程式碼規範

| 項目 | 規則 |
| ---- | ---- |
| 檔名 | 全小寫、以連字號分隔；HTML 與其專用 CSS/JS 同名（edit.html、edit.css、edit.js） |
| 共用檔名 | 固定為 base.css、api.js、ui.js、rules.js，不得任意改名 |
| HTML | 只放結構；禁止 style 標籤、內嵌 script、以行內樣式做版面 |
| CSS | 共用樣式一律寫在 base.css；單頁樣式只能寫在該頁專用檔；顏色與間距使用變數 |
| JS | 外部 script 加 defer；不使用框架與 ESM 模組語法；共用邏輯掛在固定全域命名空間 |
| 註解 | 只說明原因與限制，不寫贅述 |
| 重複 | 兩處以上使用相同邏輯即抽到共用檔 |
| 資料 | 前端不得自訂格式規則，一律依 docs/API.md 與 js/rules.js |

## 14. 預設開發流程

1. 依序閱讀：README → 專案規劃 → 檔案關聯 → API → 最新日誌。
2. 確認本次要動的檔案；若需新增共用檔，先更新專案規劃與檔案關聯。
3. 實作 HTML、CSS、JS，遵守檔案分離與共用規則。
4. 驗證：資料執行 scripts/validate-resume.mjs；頁面用瀏覽器檢查載入、操作與無障礙。
5. 更新檔案關聯（載入關係）、API（資料或動作有變時）。
6. 在當日日誌新增紀錄（編號、動作、檔案、摘要、目的）。
7. 範圍或規則有變時更新專案規劃。
