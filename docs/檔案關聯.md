# 檔案關聯

> 這份文件記錄「哪個 HTML 載入了哪些 CSS、JS」，以及「哪些 CSS、JS 必須先載入其他檔案才能運作」。
>
> 目前狀態：瀏覽頁已建立（階段 1）；管理／修改頁尚未建立。以下載入關係已依實際檔案更新，尚未建立的檔案仍標示「規劃中」。
>
> 維護規則：新增、刪除、改名任何 HTML、CSS、JS，都必須同步更新本文件，並在當日日誌留下紀錄。

## 1. HTML 載入關係（目前）

| 頁面 | 依序載入的 CSS | 依序載入的 JS | 狀態 |
| ---- | -------------- | ------------- | ---- |
| index.html | css/base.css → css/view.css | js/api.js → js/ui.js → js/rules.js → js/view.js | 已建立（階段 1） |
| edit.html | css/base.css → css/edit.css | js/api.js → js/ui.js → js/rules.js → js/edit.js | 規劃中（階段 2，尚未建立） |

載入順序即依賴順序，不得任意調換。

## 2. 檔案依賴（前置需求）

| 檔案 | 需要先載入 | 原因 |
| ---- | ---------- | ---- |
| css/view.css | css/base.css | 使用 base.css 的設計變數與共用元件樣式 |
| css/edit.css | css/base.css | 同上 |
| js/api.js | 無 | 只使用瀏覽器原生請求功能；讀取順序：後端 API → 範例資料檔（預覽模式，只讀） |
| js/ui.js | 無 | 只處理 DOM 與畫面提示 |
| js/rules.js | 無 | 只做欄位顯示與格式規則（驗證與動作值於編輯頁階段加入），不得依賴 API 或 UI |
| js/view.js | js/api.js、js/ui.js、js/rules.js | 取得資料、拆分並渲染畫面、套用顯示規則 |
| js/edit.js | js/api.js、js/ui.js、js/rules.js | 取得資料、拆成各區塊、設定動作值、表單提示、組回整份並儲存 |

## 3. 共用檔案被哪些頁面使用

| 共用檔案 | 使用頁面 | 透過哪個單頁檔案 |
| -------- | -------- | ---------------- |
| css/base.css | index.html、edit.html | 直接載入 |
| js/api.js | index.html、edit.html | js/view.js、js/edit.js |
| js/ui.js | index.html、edit.html | js/view.js、js/edit.js |
| js/rules.js | index.html、edit.html | js/view.js、js/edit.js |

## 4. 載入方式規範

| 規範 | 內容 |
| ---- | ---- |
| CSS 位置 | 一律用 link 標籤放在 head；先共用、後單頁 |
| JS 位置與屬性 | 一律用外部 script，加 defer；先共用、後單頁 |
| 禁止 | 禁止內嵌 style 標籤、內嵌 script、行內 style 屬性排版、ESM 模組語法（需支援本機直接開啟） |
| 方向限制 | 共用檔不得載入單頁檔；單頁檔之間不得互相載入；單頁檔只能載入共用檔 |
| 全域命名 | 共用 JS 掛載於固定的全域命名空間，避免變數衝突 |

## 5. 新增或修改檔案時的檢查清單

1. 這個檔案是共用還是單頁專用？共用就必須登記到「專案規劃」的共用基礎檔案清單。
2. 若為單頁專用，是否已存在相同邏輯？有就改用共用檔，不得重寫。
3. 更新本文件第 1、2、3 節。
4. 若涉及儲存流程，確認動作欄位有正確設定並隨封包送出（見第 7 節）。
5. 用瀏覽器開發者工具確認：每頁只載入預期檔案、順序正確、沒有找不到檔案。
6. 在當日日誌新增一筆紀錄。

## 6. 未來擴充（作品集啟用時）

| 情況 | 處理方式 |
| ---- | -------- |
| 作品集只在檢視頁顯示 | 不新增檔案，沿用 index.html、css/view.css、js/view.js |
| 作品集需要獨立頁面 | 新增 portfolio.html、css/portfolio.css、js/portfolio.js，並回到本文件第 1 節新增一列 |

## 7. 隱藏動作欄位的責任分工

| 檔案 | 責任 |
| ---- | ---- |
| edit.html | 放置隱藏動作欄位，不顯示給使用者 |
| js/rules.js | 定義動作值的合法清單（新增、修改、刪除、其他） |
| js/edit.js | 依操作設定動作值：預設修改、建立新履歷為新增、刪除整份履歷為刪除；並負責把各區塊組回整份合輯 |
| js/api.js | 送出時把動作值放入封包，與整份合輯一起送出；不得自行決定動作值 |

規則：動作值只有 js/edit.js 能設定；其他檔案不得寫入或改寫，避免送錯動作。

目前階段（瀏覽頁）尚未實作儲存與動作值；本節的責任分工於編輯頁階段生效。

## 8. 修改儲存流程時的檢查重點

1. 讀取仍只呼叫一次，且一次取回整份合輯。
2. 合輯要先拆成頁面區塊，編輯後再組回整份，不得只送單一區段。
3. 封包必須同時包含動作欄位與全部 9 個區段。
4. 動作值只能是動作欄位定義的四個值之一。
5. 修改完成後，回到本文件第 1、2、3 節確認載入關係沒有遺漏。
